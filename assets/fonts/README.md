# Fonts for generated images

TrueType copies of the site's fonts, used only by `next/og` (which can't read the WOFF2 files
`next/font` serves) to draw the social images for shared day plans.

- `BricolageGrotesque-Medium.ttf`: Bricolage Grotesque by Mathieu Triay
- `Inter-Medium.ttf`: Inter by Rasmus Andersson

Both are licensed under the SIL Open Font License 1.1 and were downloaded from Google Fonts.
